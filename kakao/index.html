💬 카톡 알림 연결

내 카카오톡 "나와의 채팅"으로 할 일 알림을 받게 연결하는 페이지예요. 처음 한 번, 그리고 두 달에 한 번 다시 연결할 때만 써요.

1. 카카오 개발자 사이트에서 앱 만들기 (처음 한 번)

  1. developers.kakao.com에 평소 카카오 계정으로 로그인 → 내 애플리케이션 → 애플리케이션 추가하기(이름은 아무거나, 예: "내 할 일 알림")
  2. 앱 → 플랫폼 키 → REST API 키: 키를 복사해 두고, 같은 화면의 리다이렉트 URI에 아래 주소를 그대로 등록
  3. 같은 화면의 클라이언트 시크릿: 새 앱은 기본으로 켜져 있어요. 코드를 복사해 두세요
  4. 앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 https://podokajoa.github.io 등록
  5. 앱 → 제품 링크 관리 → 웹 도메인에 https://podokajoa.github.io, https://github.com 등록
  6. 카카오 로그인 → 사용 설정 상태를 ON, 카카오 로그인 → 동의항목에서 카카오톡 메시지 전송을 "선택 동의"로 설정
2025년 12월 바뀐 메뉴 기준이에요. 폰에선 왼쪽 위 ☰를 눌러야 메뉴가 보여요. PC에서 하는 게 편해요.

2. 카카오 로그인으로 허가하기

"카카오톡 메시지 전송" 동의 화면이 나오면 체크하고 동의해 주세요. 입력한 키는 이 화면에서만 쓰이고 어디에도 저장되지 않아요.

3. 연결 코드를 GitHub에 등록하기

  1. 아래 연결 코드를 복사
  2. 저장소 Secret 설정을 열고 New repository secret (이미 있으면 KAKAO_AUTH 옆 연필 버튼)
  3. Name: KAKAO_AUTH, Secret: 복사한 코드 붙여넣기 → 저장
이 코드는 카톡을 보낼 수 있는 열쇠라서 다른 사람에게 보내지 마세요. 두 달쯤 지나 카톡으로 "연결이 곧 끝나요" 알림이 오면 이 페이지에서 다시 로그인하고 같은 이름으로 덮어쓰면 돼요.
