# 모션 트레이너

카메라로 자세를 인식해 홈트 동작을 세어 주고, 자세 교정과 들숨/날숨을 음성으로 안내하는 웹앱입니다.

- 운동: 스쿼트, 런지, 푸시업, 플랭크, 덤벨 컬
- 자세 인식: Google MediaPipe Pose (브라우저 안에서만 처리, 영상은 외부로 전송되지 않음)
- 안드로이드 크롬에서 열고 메뉴 > "홈 화면에 추가"로 설치

## 폰에서 쓰는 법
1. https://podokajoa.github.io/Motion-trainer/ 를 안드로이드 크롬으로 열기
2. 메뉴(⋮) > 홈 화면에 추가
3. 폰을 바닥이나 선반에 세우고, 몸 전체가 보이게 2~3m 떨어져서 시작

## 미소 트레이너 (smile/)
입꼬리 웃음 연습 앱입니다. MediaPipe Face Landmarker로 입꼬리 좌우 대칭, 높이, 유지 시간을 음성으로 코칭해요.

- 주소: https://podokajoa.github.io/Motion-trainer/smile/ (따로 홈 화면에 추가 가능)
- 은은한 미소 / 활짝 미소, 유지 시간과 횟수 선택, 연습 기록 저장

## 갈대 탈출 (decide/)
마음이 갈대처럼 흔들리는 사람을 위한 결정 도우미예요. 고민과 선택지를 적으면 골라 주고, 정한 결정을 지키도록 도와줘요.

- 주소: https://podokajoa.github.io/Motion-trainer/decide/ (따로 홈 화면에 추가 가능)
- 고르는 방법: 운에 맡기기(결과를 본 순간의 기분으로 속마음 확인), 둘씩 비교하기(토너먼트), 장단점 저울(무게 1~3), 직접 고르기
- 결정 잠금(3시간~일주일), 나중의 나에게 남기는 한마디, 번복할 때마다 "흔들림" 기록
- 기록은 폰(브라우저)에만 저장

## 낯선 동네 뽑기 (walk/)
안 가 본 동네의 시장·버스정류장·골목을 뽑아 주고, 거기서 찍어 올 사진 미션을 주는 앱이에요.

- 주소: https://podokajoa.github.io/Motion-trainer/walk/ (따로 홈 화면에 추가 가능)
- 지금 위치에서 거리(1~4km / 4~10km / 10~25km)를 고르면 오픈스트리트맵에서 실제 장소를 뽑아요. 다녀온 곳은 다시 안 나와요
- 미션마다 구도 힌트, 촬영 화면에 삼분할선 격자
- 사진 + 한 줄 메모 + 위치·시간 자동 기록, 다녀온 곳이 지도에 쌓여요
- 길 찾기는 카카오맵으로 연결. 사진과 기록은 폰(브라우저)에만 저장

## 새벽 시장 떡집 (mystery/)
보드게임 머더미스터리를 폰으로 옮긴 1인 추리 게임이에요. 새벽 시장 떡집 사장이 쌀가마에 깔린 채 발견되고, 8시 전에 범인을 밝혀야 해요.

- 주소: https://podokajoa.github.io/Motion-trainer/mystery/ (따로 홈 화면에 추가 가능)
- 현장 사진 조사, 용의자 3명 심문(증거 내밀기), 단서 두 개를 실로 이어 새 사실 열기
- 동료 형사 2명(NPC)이 단톡방에서 단서를 가져오고 서로 다른 추리를 펼쳐요
- 한 번 움직일 때마다 10분, 범인 지목엔 근거 3개(동기, 현장에 있었다, 거짓말) 필요
- 단서마다 처음 가진 사람(holder)이 정해져 있어서, 나중에 2~4인 모드로 넓힐 때 NPC 자리를 사람이 채우면 돼요

## 저장 검문소 (checkpoint/)
스크랩이나 나에게 보내기로 아무거나 쌓아 두는 습관을 멈추게 하는 앱이에요. 저장하기 전에 "왜 저장해요? 언제 쓸 거예요?"를 묻고, 대답 못 하면 버리는 게 기본이에요.

- 주소: https://podokajoa.github.io/Motion-trainer/checkpoint/ (홈 화면에 추가하면 안드로이드 공유 메뉴에 "검문소"가 생겨요)
- "나중에 보려고", "혹시 몰라서", "좋아서" 같은 대답은 이유로 안 받아줘요
- 쓸 때: 오늘 밤 / 내일 아침 / 이번 주말 / 다음 주 / 한 달 뒤 / 날짜 / "어떤 상황이 오면…"(30일 안에 안 오면 저절로 도착)
- 때가 되면 앱 맨 위에 "도착했어요"로 다시 나오고, 썼어요 / 미루기(딱 한 번) / 버리기 중에 골라야 해요. 구글 캘린더 알림도 넣을 수 있어요
- "안 쌓은 것"과 "써먹은 것" 기록, 파일 백업. 기록은 폰(브라우저)에만 저장

## 여행 발자국 (travel-footprints/)
갤럭시 갤러리 사진의 GPS로 여행 기록을 지도에 보여주는 안드로이드 앱이에요 (Kotlin, MapLibre).

- 설치: 폰에서 https://github.com/podokajoa/Motion-trainer/releases/download/travel-footprints-latest/travel-footprints.apk 를 받아 설치
- APK는 GitHub Actions가 main에 올라올 때마다 자동으로 만들어요. 기존 앱을 지우지 않고 업데이트하려면 저장소 Secret `DEBUG_KEYSTORE_B64`(집 PC `debug.keystore`의 base64)가 필요해요.
- 사진과 분석 기록은 폰 안에만 저장돼요.

## 삼자대면 (gpt-chat/)
미나 · Claude · GPT 셋이 단톡방처럼 대화하는 화면이에요. 폰 웹앱이 아니라 **내 PC에서만** 돌아가요.

- Claude는 Claude Code CLI(`claude -p --resume`), GPT는 Codex CLI(`codex exec resume`)로 각자 자기 대화를 이어 가요. 새 메시지만 넘겨도 둘 다 앞의 대화를 기억해요.
- API 키 없이 Claude 구독과 ChatGPT 구독 로그인으로 돌아가요.
- 왼쪽 목록에서 대화방을 여러 개 만들 수 있어요(방마다 Claude·GPT 기억이 따로, 제목은 첫 말로 자동). 더블클릭으로 이름 바꾸기, ✕로 지우기
- 📎로 사진(png/jpg/gif/webp)이나 글자 파일(txt/md/csv/json 등)을 올리면 둘 다 볼 수 있어요. 붙여넣기·끌어다 놓기도 돼요
- 영상도 올릴 수 있어요. 영상 파일은 올라가지 않고, 브라우저가 장면 사진을 뽑아 보내요. 기본은 '화면 바뀐 순간'만 골라 최대 30장(앱 화면 녹화에 좋아요)이고, 3초마다·1.5초마다·7초마다 뽑는 방식도 고를 수 있어요. 소리는 듣지 못해요(mp4 H.264 권장)
- 누가 답할지(둘 다 / Claude만 / GPT만) 고를 수 있고, "둘이 토론시키기"를 누르면 Claude와 GPT가 두 번씩 주고받아요.
- 실행: 윈도우에서 `start.bat` 더블클릭 → 브라우저에 http://localhost:3939 이 열려요. 처음 한 번은 터미널에서 `codex login`, `claude`(로그인)를 해 두어야 해요.
- 🎨 "GPT가 그리기" 버튼: 입력창에 적은 내용을 GPT가 그림으로 그려 대화창에 보여 줘요(전용 폴더 `gpt-chat/generated`에만 쓰기 가능, Codex의 이미지 생성 필요). Claude나 GPT가 앱 화면 시안을 HTML로 만들면 대화창에 작은 화면으로 바로 보여 줘요(스크립트·바깥 주소는 막아 둠)
- 대화 내용은 PC의 `gpt-chat/chat-state.json`에만 저장돼요.
