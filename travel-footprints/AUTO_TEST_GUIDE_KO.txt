여행 발자국 TEST 자동 실행 도구

1. RUN_TEST_ON_WINDOWS.cmd를 TravelFootprints 폴더 안에서 더블클릭한다.
2. 창이 끝날 때까지 별도 클릭 없이 기다린다. 휴대폰 연결이 없어도 빌드/테스트는 진행된다.
3. 결과 파일: test-reports\last-run.txt
4. 휴대폰 실행/화면 캡처에 성공한 경우: test-reports\last-screen.png

중요:
- 이 도구는 TEST 앱 (com.example.travelfootprints.demo) 전용이다.
- 기존 여행 발자국 앱을 삭제하거나 데이터를 초기화하지 않는다.
- 실제 사진을 읽지 않는 가상 GPS 18개 버전이다.
- 자동 연결을 못 찾으면 APK 빌드까지만 수행한다.
- 현재 디버깅 포트를 직접 등록하려면 같은 폴더에 device_endpoint.txt 파일을 만들고
  한 줄에 예: 192.168.10.38:40365 라고 적는다. 포트가 바뀌면 그 줄만 변경한다.
- 설치 성공/앱 시작 시도와 실제 기능 정상 작동은 다르다. 화면과 로그로 확인해야 한다.
- 로그와 화면 캡처는 PC에만 저장된다. 자동 업로드하지 않는다.
