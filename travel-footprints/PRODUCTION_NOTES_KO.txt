여행 발자국 v0.24 실제 앱 소스 (테스트 데이터 없음)

v0.24: 사진 위 글을 손가락으로 끌어 아무 곳에나 놓고, 크기는 슬라이더(아주 작게~크게), 정렬(가운데/왼쪽), 여러 줄. 앨범 큰 사진과 책 PDF에서 같은 위치로 표시(자른 사진에서도 글 위치 유지).
v0.23: 사진 위에 글 달기. 큰 사진 화면의 "글 달기"로 한 줄을 쓰고 위치(위·가운데·아래), 글자색(흰·검정), 크기를 고름. 앨범 칸, 큰 사진, 책 PDF에 그대로 표시. 글은 book.json(백업 포함)에 저장.
v0.22: 책 만들기 첫 단계. 앨범 사진의 ☆로 고르기(★), 날짜별 글쓰기(질문 3개), 책 미리보기(A5 세로), PDF 저장(다운로드/여행발자국). PDF에 GPS 정보 미포함. 선택·글은 book.json에 저장되고 백업에 포함.
v0.21: 경로선은 0.5km 단위 장소끼리만 이어 지그재그 제거하고 장소마다 점 표시. 지도 탭 핀이 겹치면 최신 여행만 보이고 확대하면 나머지가 나타남.
v0.20: 여행 경로를 진짜 지도 위 사진 이동선으로, 같은 곳은 한 곳으로 묶음(날짜 넘어도), 바다·이동 구간은 "이동 중"으로 표시.
v0.19: 여행 앨범 맨 위를 책자처럼. 여행 요약(일·곳·사진), 경로 그림, 방문한 순서, 날짜별 간 곳 표시. 목표: 여행 에세이·사진집 출간(다음: 사진 고르기, 글, 책 내보내기).
v0.18: 여행 앨범으로 새로 만듦. 여행만 모아 목록 → 날짜별 앨범 → 사진. 지도는 여행당 사진 핀 하나. 옛날 컴퓨터(Y2K) 디자인, 도트 글꼴(Galmuri, OFL) 내장. ABI를 arm64/armv7만 남겨 용량 축소.
v0.17: 지도를 전체 화면으로. 연도·지역 버튼은 위에 떠 있고, 기록 목록은 아래에서 끌어올리는 판.
숫자 원을 누르면 펼쳐지는 만큼만 확대하고, 같은 자리에 겹친 사진은 판 위쪽에 사진 줄로 보여줌.
기록·여행 후보 카드에 지역 이름 자동 표시(카드마다 대표 좌표 1개만 폰의 위치 서비스로 조회, places.json에 저장).
기록을 누르면 지도가 그 범위로 이동하고 사진 줄 표시. 사진은 앱 안의 전체 화면 보기로 열림(왼쪽/오른쪽 눌러 넘김).

v0.16: 지명 언어를 지역별로 나눔. 한국 안은 한국어, 나라 이름은 한국어, 그 외 해외 지명은 영어/로마자(없으면 현지 표기).
작은 지명·골목길 이름·물길 이름 숨김, 글자 간격 넓힘(확대 시 빽빽함 완화).
나침반·회전·기울이기 끔(오른쪽 위 버튼 옆 검은 반원). 썸네일을 못 읽으면 빈 상자 대신 사진 아이콘.

v0.15: 지도를 OpenFreeMap 벡터 지도(positron)로 교체. 지명은 OSM의 한국어 이름(name:ko)을 우선 표시하고 없으면 현지 이름.
바다·공원·배경 색을 트래블 파스텔 색으로 바꿈. 사진 핀·숫자 묶음은 그대로.
기록 백업하기/백업 불러오기 추가: points.json, trip_decisions.json, places.json을 JSON 파일 하나로 저장·복원.
APK는 GitHub Actions에서 자동 빌드(.github/workflows/travel-footprints-apk.yml).


앱 ID: com.example.travelfootprints (기존 앱 ID 유지)
버전: 18 / 0.18

v0.14: 웹 시안 대신 실제 Android MainActivity 화면을 수정.
아이보리 바탕, 세이지 초록 포인트, 여행 발자국 헤더, 파스텔 기록 카드와 확대된 실제 갤러리 썸네일.
앱 ID 및 points.json 저장 형식 변경 없음. 기존 설치 앱을 삭제하지 말고 동일한 PC 서명으로 업데이트해야 기록이 유지됨.
Android SDK 부재로 이 작업 환경에서는 APK 빌드 및 기기 실행 미검증.

v0.13 보완: 전체 지도 진입 시 국내 사진이 충분하면 국내 주요 촬영권을 우선 표시.
45일 이상, 10일 이상 반복 촬영한 장소를 여러 개 식별하여 집/직장 등 반복 방문 장소를 여행으로 단정하지 않도록 보완.
오프라인 추정일 뿐 실제 여행 여부를 확정하지 않음.
추가: 앱 시작 시 저장된 GPS 밀집 지역으로 지도를 즉시 이동
추가: 여행 후보 카드에서 해당 위치를 지도에 바로 표시
추가: 최근 사진 기록을 가로로 넘겨 보기 (최대 12묶음)
추가: 일부 국가의 아주 대략적인 한국어 위치 힌트 (서버 전송 없음)
추가: 지도 사진 클러스터 반경 확대
주의: 국가 힌트는 경계 좌표 기반의 추정이며 정확한 주소나 국가 판정이 아니다.
실제 사진: 사용자가 '사진 다시 분석'을 누르면 MediaStore/EXIF GPS 분석
캐시: 앱 내부 points.json 기존 형식 유지. 설치 시 자동 삭제하거나 초기화하지 않음.
지도: MapLibre + OSM 타일, 한국어 라벨은 타일 데이터에 의존.

주의: 이 ZIP 자체는 APK가 아니며 실제 휴대폰 빌드·실행 검증 전이다.
회사 PC의 디버그 서명으로 빌드한 APK를 기존 앱 위에 설치하지 마세요.
업데이트는 기존 앱과 동일한 서명키로 서명한 APK일 때만 가능하다.
동일한 키를 확보하기 전에는 기존 앱 삭제 및 새 앱 설치를 시도하지 마세요.

회사 PC에서 빌드 확인만 하려면 BUILD_ON_WINDOWS.cmd를 사용한다.
RUN_TEST_ON_WINDOWS.cmd는 별도 demo 전용이므로 이 운영판에는 사용하지 않는다.

v0.25: 사진 위 글을 두 손가락으로 벌리면 크기, 비틀면 회전. 회전값(rot)은 book.json에 r로 저장, PDF도 같은 그리기 코드로 회전. 슬라이더와 정렬은 그대로.

v0.26: 회전이 안 되던 문제 수정. 3도 이내 0도 붙기가 천천히 비트는 회전을 매번 0으로 되돌렸음 -> 실제 각도를 따로 쌓고 표시만 붙임.

출시용 빌드: -PstoreBuild=true 로 bundleRelease 하면 새 앱 ID(kr.travelfootprints.app)의 서명된 AAB. 워크플로 travel-footprints-store.yml. 업로드 키는 Secret RELEASE_* 4개. 앱 ID는 플레이에 올리면 바꿀 수 없으니 올리기 전에 미나 확인 필요.
