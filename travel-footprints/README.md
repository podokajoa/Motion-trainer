- **테스트 결과를 실제 사진 46,939장의 성능·정확도 검증으로 해석하면 안 됨.**

## v0.8 변경 사항
- 기존 로그의 `Unable to parse resourceUrl` 관련 가능성에 따라 `photo-counts` 텍스트용 글꼴 URL 및 Noto Sans 설정 추가. 오류와의 인과관계는 아직 미검증.
- `TravelFootprintsMap` 로그 태그에 지도 스타일 준비, 표시할 GPS 좌표 개수, 마커/클러스터/개수 레이어의 생성 여부 기록 추가.
- 지도 다운로드 서비스는 종전 OSM 래스터를 유지하며 글꼴 요청만 별도 OpenFreeMap 엔드포인트에 보냄.
- **이번 수정 후 Android APK 빌드 및 실기기 테스트 미실시.** 기존 설치 앱과 회사 PC의 서명이 다르므로 기존 앱 삭제 없이 직접 업데이트 불가.

## v0.7 변경 사항
- 세계지도 시작 위치를 아프리카에 고정하던 문제 수정. 실제 GPS 사진이 가장 밀집된 격자로 이동하고 연도/국내/그 외 지역 필터 변경 시 다시 이동.
- 여행 후보에 `국내 추정 / 해외·기타 추정`을 명시하고, 사용자가 버튼을 눌렀을 때만 대표 좌표 한 건을 기기 지역명 조회 서비스에 전달해 한국어 지역명을 요청. 조회 결과는 `places.json`에 따로 저장.
- 사진 원본이나 전체 사진 좌표 목록은 지역명 조회 서비스로 보내지 않음. 응답 언어·정확도·가용성은 기기/서비스에 따라 달라짐.
- **미완료:** OpenStreetMap 래스터 타일 내부의 현지어 지명을 한국어로 대체하는 기능. 지도 마커 렌더링과 실제 앱 UI는 이번 변경 후 실기기에서 아직 검증되지 않음.
- Windows PC에서 JDK 21 빌드를 시작하는 `BUILD_ON_WINDOWS.cmd` 추가.

## v0.6 국내 여행 추정
- 사용자 갤러리의 EXIF GPS 좌표와 촬영 날짜를 **휴대폰 안에서만** 분석하는 `TravelClassifier` 추가.
- 국내 추정/그 외 지역/전체 지역 필터와 국내 후보 검토 패널 추가. '국내 추정'은 대략적인 좌표 범위이며 정확한 대한민국 국경 판정이 아님.
- 사진이 반복 촬영된 0.1도 격자의 생활권을 추정. 10개 이상의 서로 다른 촬영 날짜와 45일 이상의 기간이 있어야 기준 지역으로 채택. 기준 부족 시 임의로 여행 확정하지 않고 '확인 필요'로 처리.
- 촬영 시각 36시간 간격, 시작점에서 80km 이동, 최대 14일 단위로 후보 그룹 구분. 생활권에서 약 70km 이상·2일 이상·12장 이상일 때만 '여행 가능성 높음' 표시. 숫자는 초기 휴리스틱이며 실기기 검증 후 조정해야 함.
- 각 후보를 사용자가 '여행 맞아' 또는 '일상 방문'으로 직접 분류 가능. 별도 `trip_decisions.json`에 저장하고 기존 `points.json`은 변경하지 않음.
- 분류 대상은 날짜가 존재하는 사진만 포함. GPS 사진 전체 지도/연도 필터는 종전대로 유지.
- 순수 Kotlin 분류 로직 컴파일과 단독 스모크 테스트 통과. 가상 46,939장 입력 분류 87ms(개발 환경 수치로 실제 폰 속도 예측 불가).
- **Android APK 빌드·UI 실행·실제 갤럭시 스캔은 이번 버전에서 미실시.**

## GPS 추출 유지
MediaStore 전체 이미지 조회 → setRequireOriginal(uri) → openInputStream → ExifInterface.latLong 경로와 좌표 유효성 검사, 100장 단위 진행, GPS 없음/읽기 실패/첫 오류 집계를 유지했습니다.
Android 29~32 저장소 읽기 권한, 33 이상 사진 읽기 권한, ACCESS_MEDIA_LOCATION을 요청합니다. Android 14 이상에서는 '모든 사진 허용'이 필요합니다.
points.json 파일명·JSON 필드·앱 ID를 유지합니다. 캐시는 앱 내부에 저장하며 지도 서버로 사진/EXIF/GeoJSON을 업로드하지 않습니다.
기존 앱을 삭제하면 캐시가 지워집니다. 업데이트 설치에는 기존 APK와 같은 서명 키가 필요합니다. 이 배포본은 개발용 debug 빌드입니다.
기존 실기기 결과 46,939장 중 15,303장 성공은 사용자가 보고한 이전 결과이며 이번 수정본에서 재현한 수치가 아닙니다.

## 지도 정책과 저작자 표시
- 타일: https://tile.openstreetmap.org/{z}/{x}/{y}.png (max zoom 19)
- 지도 아래 항상 보이는 '© OpenStreetMap contributors · ODbL' 링크 → https://www.openstreetmap.org/copyright
- User-Agent: TravelFootprints/0.3 (Android; com.example.travelfootprints)
- OkHttp 128MiB 디스크 캐시로 서버 Cache-Control / Expires / ETag / Last-Modified를 준수. no-cache 강제 헤더 없음.
- MapLibre prefetch zoom delta 0. 오프라인 팩·일괄 타일 다운로드·백그라운드 지도 수집 없음.
- OSM 공용 서버는 일반적인 소규모 대화형 열람 용도이며 SLA나 무제한 이용 보장이 없습니다. 대규모 공개 배포 전 용량에 맞는 제공자나 자체 서버를 검토하고 TileNetwork.kt의 소스/저작자 표시/정책을 함께 변경하세요.
- 지도 열람 시 타일 좌표와 IP 등 네트워크 정보가 OSMF로 전달됩니다.
- 정책: https://operations.osmfoundation.org/policies/tiles/
- 개인정보: https://osmfoundation.org/wiki/Privacy_Policy
- MapLibre: https://github.com/maplibre/maplibre-native (BSD-2-Clause). SDK 자체 법적 고지도 유지합니다.

## 빌드
Android Studio에서 이 폴더를 열고 SDK Platform 35, JDK 17 또는 21을 사용하세요. 첫 빌드에 인터넷이 필요합니다.
Windows: .\gradlew.bat assembleDebug testDebugUnitTest lintDebug
APK: app/build/outputs/apk/debug/app-debug.apk
환경별 SDK 경로가 있는 local.properties와 개인 서명 키는 배포하지 않습니다.
한글 경로 때문에 android.overridePathCheck=true를 지정했습니다. 도구 오류가 나면 영문 경로에 압축을 풀어 빌드하세요.

## 실기기 확인 절차 (아직 수행하지 않음)
1. 기존 데이터가 필요하면 앱 삭제 없이 같은 서명으로 업데이트 설치.
2. 네트워크 연결 후 OSM 지도·저작자 링크·사진 점 표시 확인.
3. 전체 사진과 위치 메타데이터 권한 허용 후 갤러리 분석.
4. 전체/검사/GPS/없음/실패 숫자를 기록하고 이전 46,939/15,303 결과와 비교.
5. 전체·2026·2025 전환 시 개수와 점이 바뀌는지, 날짜 없는 사진이 전체에만 포함되는지 확인.
6. 사진 열기, 회전/백그라운드 복귀, 권한 거부·선택 사진 허용·네트워크 차단 시 동작 확인.
7. 실제 대량 사진에서 분석 시간, 지도 이동 부드러움, 메모리, 타일 캐시 재사용은 추가 검증 필요.
