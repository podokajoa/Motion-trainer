# 시간 지킴이 (안드로이드)

앱마다 하루 제한 시간을 정해 두면

- 쓰는 동안 화면 위에 `유튜브 12분 / 30분`처럼 작게 띄워 주고
- 정해 둔 간격(예: 10분)마다 `20분 지났어요` 카드가 잠깐 뜨고
- 제한을 넘으면 화면을 덮어서 오늘 쓴 시간, 숫자로 만든 팩폭 한 줄, 내가 적어 둔 한마디(예: 책 읽을 시간이에요)를 보여 줍니다. `그만할게`를 누르면 홈으로, `5분만 더`는 미룬 횟수가 남습니다.

필요한 권한: 사용 정보 접근(앱별 사용 시간 읽기), 다른 앱 위에 표시(경고 화면), 알림.
사용 기록과 설정은 폰 안에만 저장하고 어디로도 보내지 않습니다.

설치: https://github.com/podokajoa/Motion-trainer/releases/download/timeguard-latest/timeguard.apk
